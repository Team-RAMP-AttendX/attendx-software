# Demo Script (3-5 minutes)

**0:00–0:30: Problem**
"Every day, fingerprint attendance systems fail due to dirty sensors or wet hands, causing lines and manual override nightmares. If the network goes down, attendance stops completely."

**0:30–1:00: AttendX Introduction**
"Meet AttendX. A resilient smart attendance terminal that handles fingerprint failure gracefully and survives network outages seamlessly."

**1:00–1:45: Fingerprint Attendance**
"Watch as a student checks in using their fingerprint. It's instantly validated and appears on our central dashboard as 'Present' and 'On Time'."

**1:45–2:15: PIN Fallback + Image**
"What if the fingerprint fails? AttendX allows a PIN fallback. To prevent proxy attendance, our ESP-CAM securely snaps a photo when the PIN is used. The dashboard updates, and the admin can view the image evidence."

**2:15–2:45: Late Attendance**
"The system automatically tracks time. This check-in happened after 9:00 AM, so the dashboard instantly flags the user as 'Late' and calculates the delay duration."

**2:45–3:30: Offline Synchronization**
"Now, let's simulate a network outage. I'll disconnect the Wi-Fi. The student checks in. The terminal LCD shows success because data is safely stored on local backup memory. When Wi-Fi is restored, AttendX automatically synchronizes the pending records."

**3:30–4:00: Dashboard & Analytics**
"Administrators get complete operational visibility. The dashboard tracks authentication modes—so we know exactly how many users rely on PINs—and monitors the live health and battery status of all terminals."

**4:00–4:30: Reports**
"We can filter all historical records by date, role, or authentication mode, and generate an instant Excel export for administrative reporting."

**4:30–5:00: Impact & Closing**
"AttendX makes attendance capture more reliable, observable, and resilient. Thank you."
